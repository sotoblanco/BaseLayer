# Demo: Code, Sheets & Canvas

One tiny idea — normalizing an RGB pixel — taught through all three BaseLayer modalities.

## Learning Arc
1. **Lesson 1 (drawing):** sketch the pipeline. Build visual intuition before any formula.
2. **Lesson 2 (spreadsheet):** normalize the pixel with cell formulas. Feel the math stepwise.
3. **Lesson 3 (code):** implement `normalize_pixel()` in Python, verified by unit tests.

## Modalities in this Course
- **Drawing Canvas:** blank chalkboard, AI-graded against a rubric. No image file needed.
- **Spreadsheet:** a personal sheet copy is provisioned from the inline template. No template ID needed.
- **Code Studio:** Monaco editor + sandbox. Starter fails, solution passes.
